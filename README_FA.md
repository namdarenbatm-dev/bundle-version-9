# Techno Bundle — نسخه ۹ (بسته اصلاح‌شده)

## نصب روی GitHub Pages
1. محتویات این ZIP را در ریشه مخزن GitHub بارگذاری کنید.
2. از Settings → Pages انتشار مخزن را فعال کنید.
3. وب‌سایت HTTPS را باز کنید؛ سپس از مرورگر گزینه Install / Add to Home Screen را بزنید.
4. اگر نسخه قبلی نصب است، پس از انتشار نسخه جدید یک بار سایت را با اینترنت باز کنید تا Service Worker نسخه ۹.۱ جایگزین کش قبلی شود.

## قابلیت‌ها
- لوگوی ارسالی رسمی توسن تکنو و فونت یکان ارسالی
- محصول هدف ثابت: کارتخوان اکبند
- انتخاب محصول محرک: کش‌لس یا کارتخوان استوک
- فرمول ظرفیت باندلینگ هر محرک: قیمت فروش محرک − بهای تمام‌شده محرک − سود ثابت محرک − بودجه بازاریابی هر کارتخوان
- قیمت کارتخوان پیش از باندلینگ = قیمت پایه + بودجه بازاریابی هر کارتخوان
- تخفیف کل هر بسته از ظرفیت محرک‌ها تجاوز نمی‌کند و قیمت نهایی از کف رقابتی پایین‌تر نمی‌رود
- سود خالص محاسباتی پس از کسر بهای تمام‌شده، بودجه بازاریابی و سود ثابت محصول محرک کنترل می‌شود
- تعداد کارتخوان اکبند در هر بسته باید از تعداد محصول محرک بیشتر باشد
- ترتیب اولویت‌ها، انتشار/لغو انتشار، پیشنهاد اصلی و حداکثر یک ارتقا
- خروجی CSV برای Excel و چاپ/ذخیره PDF
- ذخیره تنظیمات و وضعیت انتشار در همان مرورگر و پشتیبانی آفلاین

## نکته مهم
همه مبالغ ورودی در واحد تومان وارد می‌شوند؛ انتخاب «ریال» فقط نمایش خروجی را به ریال تبدیل می‌کند. اعداد پیش‌فرض نمونه‌اند و باید با ارقام واقعی مصوب جایگزین شوند. آزمون‌های نحوی و محاسبات نمونه انجام شده‌اند، اما تضمین «بدون هیچ خطا» در همه مرورگرها بدون آزمون میدانی ممکن نیست.
